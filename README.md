# Wordnod

A Markdown viewer that never edits behind your back. You read a document; where you want a change, you mark the
passage and say what it should become, yourself or through an AI. Nothing reaches the file until you press **Keep**.

This repository holds Wordnod's **releases** and its **support desk** (issues). The source is kept elsewhere.

## Test builds

Wordnod is in testing. Each test build is a pre-release on the [Releases](../../releases) page:

- `WordnodViewer-win-Setup.exe` installs it for your user (no administrator) and keeps it up to date.
- `WordnodViewer-win-Portable.zip` is the same build in a folder, with no install and no update.

A test build runs only with a key from its developers; ask for one before installing.

## Reporting a problem

In the viewer, right-click the title bar › **Report a problem…**: it opens the log folder and the report form here
with the version filled in. Say what you did and what you expected, and attach the newest log file. The log holds
file names and what the viewer did, never the words of your documents.
